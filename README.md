# RAG (FAISS + LM Studio + Metadata + Token Control)

Этот проект — пример Retrieval-Augmented Generation (RAG), который использует:

- **FAISS** — быстрый векторный поиск
- **Nomic Embeddings** (через LM Studio)
- **Mistral-7B-Instruct** или другую LLM, подключённую через LM Studio
- **Фильтрацию по метаданным**
- **Ограничение токенов**
- **Переформулировку вопроса для улучшения поиска**
- **Автоматическую сборку контекста с указанием источников**

Основные скрипты:

- `build_all.py` — загрузка документов, разбиение на чанки и построение эмбеддингов
- `run_chat.py` — диалог с ИИ и поиск по базе документов (Q&A)

---

## Назначение папок и файлов

- `data\` - исходные файлы
- `corpus\` - обработанный текст файлов (преобразованные в markdown,  + создается доп. файл с метаданными файлов)
- `.\cunks.jsonl` - сюда сохраняются фрагменты текста (чанки) из всех документов и их метаданные
- `.\embeddings.npz`- здесь хранятся вектора (эмбеддинги) текста из файлов
- `.\embeddings_meta.json` - здесь хранятся метаданные сформированных эмбеддингов
- `.\logs.log` - логи, формируемые при выполнении кода для отслеживания скорости и корректности работы программы

## 🚀 Установка

### 0. Создание и активация виртуального окружения (рекомендуется)
Это позволит устанавливать зависимости только для проекта.

```bash
python -m venv venv
source venv/bin/activate   # Linux / macOS
venv\Scripts\activate      # Windows
```

### 1. Устанока зависимостей

```bash
pip install -r requirements.txt
```

## 💡 Работа с проектом

1. Запустить сервер LM Studio и загрузите нужные модели (LLM и embeddings).
2. В файле `src/utils.py` укажите:
- `EMBEDDING_MODEL`
- `LLM_MODEL`
- адрес сервера LM Studio `SERVER`.

3. Добавить документы в папку `data/`
4. Построить индексы и эмбеддинги

```bash
python build_all.py
```
5. Запустить чат-интерфейс

```bash
python run_chat.py
```

6. Задавать вопросы — ответы будут формироваться на основе документов.
